# Estructura de imágenes de proyectos

Para cada proyecto nuevo, coloca la portada en `principal` y las capturas futuras en `galeria`:

`pimages v2/contratistas/<slug>/principal/principal.png`
`pimages v2/contratistas/<slug>/galeria/galeria-01.png`

Slugs disponibles:

- eug-roofing
- rivas-edge-construction
- magic-marble-tile
- em-general-contractor
- rainy-time-roofing
- pro-mexas-painting
- guzman-painting
- burrito-tile-stone
- procoat-drywall
- avellaneda-construction
- iraheta-prime
- ms-landscaping

La aplicación toma las imágenes organizadas aquí como fuente de verdad. La primera imagen encontrada en `principal` se muestra como portada; las imágenes de `galeria` quedan registradas para futuras mejoras. Si un proyecto no tiene portada, no se le asigna una imagen de otro proyecto.
